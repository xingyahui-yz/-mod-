## 关键约定（避免重复犯错）

1. **`crypto.randomUUID()`** 在 jsdom 里可用——直接用，不要 mock
2. **act() 包裹**任何会触发 setState 的 hook 调用；测试里读 `result.current.graph` 也要在 act 内
3. **数据模型不动**——只在 `graph.ts` 加新操作，不要改 `types.ts` 现有字段
4. **测试命名**：`[data-testid^="node-box-"]` 避免与 `node-graph-canvas` 冲突
5. **dev server**：`ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm run dev`
