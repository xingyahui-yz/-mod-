## 2. v0.6 bug 修复详情（commit 1）

### 根因

```ts
// v0.6 原代码
const connectFn = useCallback((from, to) => {
  let outcome = { ok: true }
  setGraph(prev => {
    const r = connect(prev.present, from, to)
    if (r.ok) { outcome = { ok: true }; return r.graph }
    outcome = r; return prev
  })
  return outcome  // ← React 18 batch 下读取的是初始值，不是 updater 内的更新值
}, [])
```

React 18 的 `setState(updater)` **updater 不是同步执行**——它在 act flush 阶段才跑。closure 捕获的 `outcome` 在 `setGraph` 调用返回后立即读，读到的是初始值 `{ok:true}`。

### 触发场景

connect 失败时（自环、端口不存在、类型不兼容等），返回的 `outcome` 错误地是 `{ok:true}`。但 v0.6 测试只测成功路径（初始值匹配），bug 未暴露。

### 修复

用 `flushSync` 强制 updater 同步执行：

```ts
import { flushSync } from 'react-dom'

const connectFn = useCallback((from, to) => {
  let outcome: { ok: true } | { ok: false; reason: string } = { ok: true }
  flushSync(() => {
    setHistory(prev => {
      const r = connect(prev.present, from, to)
      if (r.ok) { outcome = { ok: true }; return commit(prev, r.graph) }
      outcome = r; return prev
    })
  })
  return outcome
}, [])
```

**trade-off**：每次 connect 触发一次同步 re-render。编辑器交互频率下可接受；批量导入时未来考虑优化。

### 回归测试

新增测试 `connect 失败返回值正确`：

```ts

```

## 3. v0.7 新功能详情（commit 2）

### 3.1 HistoryState + commit()

```ts
export const HISTORY_LIMIT = 100

export interface HistoryState {
  past: NodeGraph[]
  present: NodeGraph
  future: NodeGraph[]
}

function commit(prev: HistoryState, next: NodeGraph): HistoryState {
  if (next === prev.present) return prev  // no-op（保同引用 → 不虚假 updatedAt）
  const basePast = prev.past.length >= HISTORY_LIMIT
    ? prev.past.slice(prev.past.length - HISTORY_LIMIT + 1)
    : prev.past
  return {
    past: [...basePast, prev.present],
    present: next,
    future: []
  }
}
```

所有 mutation（addNode/removeNode/moveNode/disconnect/importJson）走 `commit()`；connect 走 `flushSync + commit()`（因为还要返回 outcome）。

### 3.2 undo / redo / canUndo / canRedo

```ts
const undo = useCallback(() => {
  setHistory(prev => {
    if (prev.past.length === 0) return prev
    const last = prev.past[prev.past.length - 1]
    return { past: prev.past.slice(0, -1), present: last, future: [prev.present, ...prev.future] }
  })
}, [])
// redo 类似反向
```

自身不入栈（直接 setHistory，不走 commit）；past/future 空时为 no-op。

### 3.3 UI（RelicEditor）

- toolbar 加 ↶ 撤销 / ↷ 重做 按钮（`disabled={!canUndo/canRedo}` + tooltip 快捷键提示）
- 全局 keydown 监听：
  - `Ctrl/Cmd+Z` → undo
  - `Ctrl/Cmd+Shift+Z` → redo
  - **`Ctrl+Y` (Win/Linux) 或 `Cmd+Y` (Mac)** → redo
  - `isEditableTarget()` 守卫：INPUT/TEXTAREA/SELECT/contentEditable 焦点时跳过，让浏览器原生 undo 生效

### Q4 — Mac Cmd+Y 作为 redo 别名

**决策**：(b) Mac 也支持 `Cmd+Y` 作为 redo 别名。

**理由**：原设计文档只列了"Windows/Linux 的 Ctrl+Y"。grilling 时认为 Mac 高级用户习惯 Cmd+Y（类似 Photoshop/Sublime 风格）。修改一行即可：


### Q5 — importJson 同内容不入栈

**决策**：(c) importJson 单独走 `JSON.stringify` 深比较，相同内容视为 no-op。

```ts
const importJson = useCallback((json: string) => {
  try {
    const restored = deserialize(json)
    setHistory(prev => {
      if (restored === prev.present) return prev                                  // 同 ref
      if (JSON.stringify(restored) === JSON.stringify(prev.present)) return prev  // 同内容（Q5）
      return commit(prev, restored)
    })
    return { ok: true }
  } catch (err) {
    return { ok: false, error: err instanceof Error ? err.message : String(err) }
  }
}, [])
```

**理由**：commit() 保持纯引用判断（简洁、无 O(n) 开销）；importJson 是少数用户主动重做的场景，加深比较值得。

### Q7 + F2 — dev warning 分层

**决策**：(c) 分层放置。

```ts
// src/node-editor/useNodeGraph.ts 文件顶部（Q7：模块级单次提醒）
if (import.meta.env.DEV && !(globalThis as any).__v07_history_limit_warned) {

    '[mod-studio v0.7] useNodeGraph HISTORY_LIMIT = 100 (hardcoded). ' +

    'Pass useNodeGraph(id, type, initial?, { historyLimit?: number }) to override.'
  )

// useNodeGraph 函数内（Q9：实例级输入校验）
function resolveHistoryLimit(options?: { historyLimit?: number }): number {
  const DEFAULT = 100
  const v = options?.historyLimit
  if (v === undefined) return DEFAULT
  if (!Number.isFinite(v) || v < 1 || !Number.isInteger(v)) {
    if (import.meta.env.DEV) {
      console.warn(`[mod-studio] useNodeGraph: invalid historyLimit=${v}, fallback to ${DEFAULT}`)
    }
    return DEFAULT
  }
  return v
}
```

### Q9 — historyLimit 边界校验

**决策**：(c) 校验 + dev warn + fallback 到默认 100。

**非法值**：`undefined`（用默认）、`NaN`、`< 1`、非整数、浮点数 → fallback + warn。
**合法值**：用传入值；非默认且合法 → 文件顶部单次 info（Q7）。
